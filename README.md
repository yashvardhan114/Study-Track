# StudyTrack – Student Study Planner

StudyTrack is a student study planner web application designed to help students organize their daily study tasks and subjects.

## Live Demo
https://yashvardhan114.github.io/Study-Track/

## Features
- Add new study tasks
- Edit and delete tasks
- Mark tasks as completed
- Add and delete subjects
- Search tasks
- Filter tasks by subject
- Set task due dates
- Upcoming tasks section
- Save data using Local Storage
- Responsive mobile-friendly design

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Project Purpose
The purpose of StudyTrack is to help students manage their study routine and keep their academic tasks organized.
